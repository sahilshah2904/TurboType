# Phase 6 review on your laptop

Use the existing [LAN game](http://192.168.0.31:5173/TurboType/). It serves this feature checkout; GitHub Pages is not deployed. No repeated review of accepted cars, tracks or music is needed.

1. Open the base link without a `#/...` ending. Watch the fullscreen 5.6-second TurboType title reveal; Enter then opens Welcome. Set Motion to Full and effects to High to see the animation. Low/Reduced intentionally show the finished title immediately. For a returning visit use Settings → Replay opening. Try Skip opening once; it should still finish preparing essentials.
2. Open How to play → Guided tutorial. Complete `Go`, then deliberately type `cx`, Backspace, `at`, then the clean rhythm sentence. Check the correction feedback and tutorial completion. Escape should pause, and resume should count down.
3. Try optional Find my pace. Type for thirty active seconds, apply the suggested pace, then check Quick Race's opponent pace. Manual pace selection and Skip should also work. A paused race must keep its original setup until Retry/New race.
4. Enable “Go straight to hub next time” in Welcome or Settings. Reopen the base link: it should go to Hub. Replay links must still work. In Quick Race, Advanced / Replay should contain the numeric seed; Retry same race and New race should both work.
5. Check the new pages in your usual laptop window and fullscreen. Try Tab/Enter, Larger typing text, Low effects and Reduced motion. Text and the active lesson's typing/Pause controls should stay readable and reachable. Sound controls remain only in Settings.

6. Race with Full motion/High effects and type steadily: inspect the travelling air ribbons, passing gusts and all five cars' slipstreams. Pause should clear wind; Low/Reduced should disable it. On Hub, no Track preview/ready labels should remain. Settings learning actions should align in rows like the display controls.

Report any awkward wording, cramped layout or confusing step. Phase 6 implementation and automated testing are complete once the recorded checks pass; your visual/interaction acceptance is the remaining gate before merging its PR. Campaign maps are the next phase after that acceptance.
